### Featured Projects

**🧠 [Brain Tumor Segmentation: Hybrid U-Net + GNN + SAM](https://github.com/ArpanMoharana/Hybrid-CNN-GNN-with-SAM-for-Brain-Tumor-Segmentation)**
- Hybrid deep learning pipeline combining U-Net, Graph Neural Networks, and SAM for brain tumor segmentation on the BraTS MRI dataset (4 imaging modalities).
- Achieved a **0.85 Dice Score**, compared with 0.83 for a standard U-Net and 0.78 for MobileNet.
- Built with PyTorch, PyTorch Geometric, and OpenCV. *Submitted to Springer Nature (under review).*

**🔎 [Semantic RAG-Based Question Answering System](https://github.com/ArpanMoharana/Semantic-Vector-RAG-QA-System)**
- Fully local retrieval-augmented generation system using LangChain, ChromaDB, Hugging Face MiniLM embeddings, and Ollama (Mistral 7B), with no external API dependency.
- Pipeline covers ingestion of 100+ document chunks, text splitting, embedding generation, and cosine similarity retrieval.
- Evaluated retrieval quality with Hit@K and Mean Reciprocal Rank.
